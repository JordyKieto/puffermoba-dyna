# E8 — The dream hallucinates XP for off-distribution play (diagnosis)

**The one-line result.** For the same real actions, the world model pays XP that the
real game never pays, and it does so **only for behaviour outside its training data**.
With the dream-PPO policy's actions, E5 predicts ~17,000 XP per 1k hero-steps even one
step at a time, where the real game paid 0. For the shipped net's actions it is roughly
right (741 vs 624). This is how every dream-trained policy (E7) and the planner (E10)
were fooled.

- **Status:** concluded, 2026-09-27. Evidence class **M** for the audits; **smoke** for
  the fixes (single seed, ~30 updates).
- **Tool:** `scripts/moba/dream_vs_real_reward.py`.
  1. Plays real games with a team's actions on radiant against the shipped net on
     dire (C arena).
  2. Records every state and action.
  3. Feeds the **same actions** to the world model in two ways: teacher-forced (one
     step from each real state) and open loop over 128-tick windows (how dream PPO
     trains).
  4. Compares each reward component with what the real game paid.
- **Results:** `results/moba/dream/*.json`. Tables generated by
  `results/moba/make_figures.py`.

|---|---|---|---|---|---|
| E5 @20,500 | ppo | real game | -0.00 | 0 | 0.000 |
| E5 @20,500 | ppo | dream, teacher-forced | -0.00 | 16992 | 0.000 |
| E5 @20,500 | ppo | dream, open loop 128 | 0.16 | 4074 | 0.065 |
| E5 @20,500 | net | real game | 2.94 | 624 | 0.194 |
| E5 @20,500 | net | dream, teacher-forced | 0.14 | 741 | 1.639 |

- **XP is the exploited signal.** It is badly over-paid for PPO and random actions, even
  teacher-forced, so it isn't only compounding rollout drift.
- **Deaths are under-predicted and towers over-predicted** for the shipped net's play.
  Both matter less than XP for the policies.

## How XP is modelled (why it can do this)

- **A regressed per-tick change:** a hero field, predicted as a change, with a change
  gate. There's a yes/no BCE head (weight 0.2) and a Huber value loss (weight 1), and no
  event structure.
- **Rules after prediction:**
  - XP is rounded, and **never decreases** (rule R7);
  - level is recomputed from XP (R4), and max stats from level (R5).
- **In the real game XP is an event:** a unit dies near the hero, and the XP is shared
  with allies within 7 cells. The model is never told that.

- **XP loss ×100:** a better one step, but open loop is worse (PPO 8,267; the net's
  1,527 vs 612 real). **Not a fix.**
- **Clamp off (rule R7), evaluation only:** the one-step hallucination is unchanged
  (~18k). Open-loop XP turns two-sided: with a signed reward the net's play goes
  strongly negative. The clamp was *hiding* large two-sided noise.
- **Clamp off, fine-tuned:** worse everywhere. **Keep the clamp.**
- **What does help:** training on the policy's own real games (E9).
