# E36: dream-PPO reward-structure sweep (3 generations, 73 arms): the first real wins

**Status:** concluded 2026-10-05.

**Verdict:**
- **Dream policies won real games against the shipped net for the first time:** 25 wins in 4,380 radiant games.
- **Long dream episodes (512–1,024 ticks) are what produce them.** Reward variants matter much less.
- Wins are rare (≈0.6–7% per arm) and do not reproduce reliably across seeds.
- **Dire: 0 wins in 4,380 games.**

All numbers come from `results/moba/dream/SWEEP_TABLE.md` (generated by `scripts/moba/ppo_sweep_table.py` from each
arm's `arena.jsonl`). Arm directories are in `results/moba/dream/{rw,gb,g3}/<arm>/` (train log, policy, real games).

## Setup (every arm)
- **Dream:** fleet20e ×1.5 @500, the calibrated world model (E35).
- **Policy:** arm C (PufferPolicy + MinGRU, `runs/dream_ppo/p7/puffer_ours`), fine-tuned unless noted. Ours plays a random
  side against the shipped net in each dream game.
- **Training:** 64 envs, lr 3e-4, 2 epochs, 2 minibatches. Episodes start at a uniformly random tick of a real game
  (memory warmed on 8 real ticks).
- **Evaluation:** 60 real games per side against the net (`mobawm/rl/arena.py`).
- **Infrastructure:** one A40 pod per arm (`runs/pod/rw_arm.py`). In-place relaunches take about 15–30 s
  (`SKIP_SETUP=1`).

## New reward terms (dream only, `mobawm/rl/dream_ppo.py`)
| flag | what it rewards |
|---|---|
| `--xp-scale`, `--death-scale` | rescales the game's XP and death terms |
| `--push-k` | progress per cell toward the enemy ancient |
| `--siege-k`, `--siege-radius` | each tick near a living enemy tower |
| `--anc-k` | enemy-ancient health lost, given to the attacking team |
| `--team-share` | every hero gets its team's mean reward |
| `--zero-sum` | the hero's reward minus the enemy team's mean |
| `--side` | train one side only |

## Generation 1 (24 structures, 1.7M steps)
- **Helped as radiant:**
  - zero-sum tower damage: 2.0 towers per game;
  - no death penalty: 1.9;
  - siege presence: 1.8;
  - arm C before training: 1.6.
- **Hurt:**
  - big per-tower bonuses;
  - team-only rewards;
  - dropping XP (with no XP the policy stops moving: 0 towers).
- **Long episodes (512–1,024 ticks)** had to be relaunched once: they need `--rollout == --episode`.
- **`win_game_1024`** (the game's reward plus win/loss ±100, 1,024-tick episodes) won **2/60** real games, the first ever,
  and took 2.8 towers per game.

## Generation 2 (24 arms: the generation-1 formula at several strengths, episode lengths and seeds)
- **Wins:** long-episode arms won 15 real games across 13 arms; 128-tick arms won 1 across 16.
- **`wg1024_2x`** (`win_game_1024` at 2× steps) won **4/60**. It was the only policy that out-took the net in the dream
  (0.328 vs 0.297 towers per episode).
- **The same recipe with another seed won 0.**

## Generation 3 (29 arms: long episodes + win reward, 4× steps, continuation from the best policy, dire-only)
- **Towers:** most arms take 2.0–3.0 towers per game as radiant.
- **Wins:** 9 in 1,440 radiant games (0.6%). They did not grow with 4× steps (group A: 0 wins over 3 seeds).
- **Best:** `J_envs128_4x_s2` won 3/60 and took 3.0 towers per game.
- **In the dream,** the net out-takes ours 2–4× in every generation-3 arm.
- **Dire-only arms** (`--side dire`, from arm C and from the best policy) never took a tower in the dream: ours 0.000
  vs the net 0.58–0.81 towers per episode. They first ran on stale code (in-place relaunches did not push code); the
  launcher now always pushes.

## The winning formula, concretely
| setting | value |
|---|---|
| reward | the game's own reward: death −0.16, XP +0.0067 per point, tower kill +0.64 to the nearest hero |
| win/loss | ±100 to every hero of the team when an ancient falls in the dream |
| shaping | none |
| episodes | 1,024 ticks (`--episode 1024 --rollout 1024`) |
| start | arm C |
| steps | 2–4× the 1.7M baseline |

`J_envs128_4x_s2` is this recipe with 128 envs, 6.8M steps and seed 2.

## What it does not show
- **Reliable wins:** win counts of 0–4 per 60 games swing with the seed.
- **Any dire play:** every arm loses every dire game.
- **Beating the net in the dream:** only one arm (`wg1024_2x`) ever did, and it did not reproduce.
