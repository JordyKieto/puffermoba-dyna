# E33: plain E12 at lr 1e-4 (P1)

**Status:** concluded 2026-10-04. **Verdict: P1 @1000 is the new best world model and the default dream.**

## Question
Is the base recipe still improving if the only change is a lower learning rate?

## Setup
- **Start:** E12 @4000.
- **Changes:** none to the recipe (batch 768, rollout lanes, spans up to 4,096, decay 64/0.02, `--store-cpu`)
  except `--lr 1e-4`.
- **Length:** 1,000 updates.
- **Scoring:** every checkpoint by the 100-game tower evaluation.

## Results (`results/moba/tower_big/TABLE.md` § p1_e12_lr1e-4; validation from `runs/token_wm/p1_e12_lr1e-4/train.log`)
| | E12 @4000 | P1 @1000 |
|---|---|---|
| tower precision | 40% [37–43] | 40% [37–43] |
| tower recall | 65% | **71%** |
| siege damage (dream/real) | 0.65× | **0.77×** |
| predicted falls (1,561 real) | 2,526 | 2,745 |
| events recall macro | 57% | **60%** |
| hero position error @32 ticks | 4.59 | **3.85** |
| val loss expert / random | — | 2.563 → **2.215** / 1.780 → **1.426** (from @125) |

- Tower precision stays at 34–40% at every checkpoint, so the run is stable.
- Validation losses are still falling at update 1,000.
- The grid-CNN line at the same learning rate (S2) is no better on towers.
  The extra architecture (E29–E31) has not earned its place.

## Decision
- `runs/token_wm/p1_at1000` (md5 `8438afe5`) is the default `--wm` for `dream_ppo`, `plan_mpc` and
  `dream_vs_real_reward`.
- Next: the same recipe, scaled out (E34).

**Artifacts:** S3 `moba/runs/p1_e12_lr1e-4` (8 checkpoints + 8 tower scores).
