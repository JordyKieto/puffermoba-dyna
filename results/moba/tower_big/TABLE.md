# 100-game tower evaluation (scripts/moba/tower_eval_big.py)

Held-out games 900–999, 128-tick open-loop windows every 64 ticks (4,017 windows), 1,561 real tower falls (overlapping windows count a fall up to twice). Precision/recall of falls within ±32 ticks; siege damage = dream/real HP for towers losing ≥ 800 HP in a window. 90% per-game bootstrap intervals.
